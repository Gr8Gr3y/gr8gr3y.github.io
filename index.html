Core capabilities for local e-book libraries

Designed around direct Android filesystem workflows for readers who maintain structured personal libraries across multiple folders and reading apps.

01. Built-in Android File Manager & Multi-Folder Queue

Browse internal shared storage and SD directories, bookmark favorite library folders, create subfolders, copy or move files with per-conflict prompts, and collect e-books from multiple locations into a single batch processing list.

02. In-Place Metadata & Cover Editing

Read and update title, authors, series, sequence number, year, publisher, ISBN, language, and genres directly inside FB2, FB3, EPUB, KEPUB, MOBI, AZW3, unencrypted AZW8/KFX, PDF, and Markdown files.

03. Conditional if() Templates & Regex Rules

Build custom filename and directory templates with nested conditional expressions, automatic zero-padding for series numbers, transliteration, case normalization, and regular expression cleanup rules.

04. Android Share Integration & Tablet Layout

Send single files, multiple books, or entire folders directly into AeBRen from any Android file manager via the system Share menu, with an adaptive two-pane layout on tablets.

Supported formats & editions

AeBRen never cracks or removes DRM; DRM-protected files are automatically skipped or kept read-only.

Read & write metadata FB2, FB3, EPUB 2/3, KEPUB, MOBI, AZW / AZW3, AZW8 / KFX (unencrypted), PDF, Markdown (YAML), *.fb2.zip / *.zip
Read-only metadata DjVu
Free Tier Ad-supported via Google AdMob (with Google UMP consent), up to 20 renamed files per day, built-in file manager, metadata editor, light Soft-Touch themes, and core renaming templates.
Pro Access (in-app) Removes ads and daily limits; adds dark & light Soft-Touch themes, extended template tags, automatic folder cataloging, book content & PDF metadata helper (text/region selection, fragment OCR, open bibliographic lookup), cover replacement, and JSON settings backup.

Local-first privacy by design

Your books, folder paths, annotations, and covers stay strictly on your Android device.

  • No user accounts, sign-in walls, or developer cloud servers storing your library.
  • Storage permissions are used exclusively upon your action to browse directories, read metadata, and rename or update local files.
  • In the Free tier, Google Mobile Ads SDK (AdMob) and Google UMP SDK are used solely for ad delivery and regional privacy consent (GDPR/CCPA).

Основные возможности для локальных библиотек

Спроектировано для прямой работы с файловой системой Android и поддержания порядка в больших коллекциях книг из разных папок и читалок.

01. Встроенный файл-менеджер и общая очередь обработки

Навигация по внутренней памяти и каталогам, избранные папки, создание подпапок, копирование и перемещение с гибким разрешением конфликтов и сбор книг из разных директорий в единый список.
